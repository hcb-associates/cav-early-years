**Cardiff and Vale Early Years (0-5 years) Population Health Assessment**

This repository provides data and code used for a 2024 analysis of population health measures relevant to understanding the health of children in the early years (0-5 years) in the Cardiff and Vale of Glamorgan region.

To replicate the analysis you can download the data and Rmd file.

Please note due to the use of Patient Identifiable data, information relating to NHS admissions and Emergency Department attendances for the region are not provided.

You will find the code for these measures asterixed out.
